# Customer-Behavior-Analysis
Overview

This project demonstrates an end-to-end data analytics workflow, starting from raw data ingestion to business insights and visualization.
The goal is to analyze the dataset, clean and transform the data, run analytical SQL queries, and present insights through an interactive Power BI dashboard and a concise business report.
The project highlights skills in Python, SQL, data analysis, and data visualization, following industry best practices.

Tools & Technologies

Python – Data loading, EDA, and data cleaning
Libraries: pandas, numpy, matplotlib, seaborn
PostgreSQL – Data storage and analytical SQL queries
SQL – Joins, aggregations, filtering, and business metrics
Power BI – Interactive dashboard and data visualization

Project Workflow

Data Loading
Loaded raw dataset into Python using pandas
Exploratory Data Analysis (EDA)
Understanding data structure and distributions
Identifying missing values, outliers, and inconsistencies
Generating summary statistics and visual insights
Data Cleaning & Preprocessing
Handling missing values
Removing duplicates
Standardizing formats and column names
Preparing data for SQL and visualization
SQL Analysis (PostgreSQL)
Imported cleaned data into PostgreSQL
Wrote SQL queries to extract business insights
Performed aggregations, rankings, and trend analysis
Dashboard Development (Power BI)
Connected Power BI to PostgreSQL
Built interactive dashboards with KPIs and filters
Visualized trends, comparisons, and key metrics
Reporting & Presentation
Created a structured analytical report
Designed a concise PPT using Gamma to present insights clearly
